# 乃木フェス イベントシミュレーター — フルBG 225時間対応版

## フルBG
- プレイ画面は「計測する」ボタンのみ。
- 日付・起床就寝・精度・BG時間・日別スナップショットに依存しない225時間（810,000秒）の一括計算。
- 通常曲BGでアイテムを獲得、イベント曲BGで875個ずつ消費。
- 所持上限99,999個、イベント曲BGの1セット上限114回。
- イベント曲BGのセット最終回は15秒の待機時間を省略。
- 計測結果をブラウザ内に保存。設定変更後は再計測が必要。
- ResultはフルBG専用表示。日別Resultや日別セット履歴は表示しない。

## 混合モード
従来の日別設定・確定処理を維持。
